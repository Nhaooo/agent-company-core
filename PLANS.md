# Execution plan

This repository is a fresh extraction from a private source repository. The
private repository remains the source of truth and is never modified by this
project.

## Milestones

1. Foundation: package metadata, Apache-2.0 licensing, typed contracts,
   provider-neutral model protocols, routing, and a clean import surface.
2. Durable runtime: mission lifecycle, SQLite persistence, approvals, STOP,
   recovery, memory, audit logging, agent delegation, and tool registration.
3. Integrations and reference app: restricted skill runner, optional Google,
   Temporal/PostgreSQL adapters, and a small localhost reference application.
4. Quality and publication review: tests, lint, type checking, build,
   secret/PII scans, documentation, and local commits.

Each milestone is tested and committed before the next milestone starts.
