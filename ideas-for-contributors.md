# Ideas for contributors

These are genuine areas that remain open in the alpha implementation:

1. Add a PostgreSQL repository that conforms to the SQLite store behavior and
   includes migration and concurrency tests.
2. Add a Temporal workflow package with replay tests and documented retry
   semantics.
3. Add a container-backed skill runner with a concrete isolation threat model.
4. Improve memory retrieval with pluggable embedding indexes and scope tests.
5. Add independent contract tests for more model providers without requiring
   credentials in CI.
