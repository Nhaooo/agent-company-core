# Roadmap

## 0.1.x

- Harden repository interfaces and add more conformance fixtures.
- Add a first-class async PostgreSQL repository with migration tests.
- Add a tested Temporal workflow package with deterministic replay fixtures.
- Improve memory ranking and add an embedding-backed implementation.
- Add richer approval APIs and explicit operator authentication hooks.

## Later

- Container-backed skill execution with documented isolation guarantees.
- Additional provider adapters, each with independent contract tests.
- Reference UI and operational metrics that never imply work not actually run.

The order is provisional. No adoption, performance, or compatibility claim is
made until it is measured and documented.
