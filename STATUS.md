# Status

The v0.2.0 impact sprint is implemented and publicly released. The public
GitHub repository and PyPI packages `agent-company-core==0.1.0` and
`agent-company-core==0.2.0` are live.

The candidate includes optional Anthropic and OpenAI-compatible adapters, an
offline CLI and starter scaffold, eleven runnable examples, a MkDocs site, a
provider matrix, multi-version CI, Dependabot, Scorecard, and package smoke
tests. The 29-test suite, Ruff, strict mypy, package build, Twine metadata
validation, pip-audit, fallback scan, official Gitleaks scans, release CI, and
fresh PyPI install smoke test pass. The restricted runner remains disabled by
default and is explicitly not a hostile-code sandbox.
